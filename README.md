# AD (Acceso a Datos)

Repositorio de la asignatura **Acceso a Datos (DAM2)** con los proyectos Maven de NetBeans y los materiales teóricos/prácticos.

## Proyectos NetBeans (Maven)

- `Biblioteca_MySQL_JDBC`
- `Biblioteca_SQLite_JDBC`
- `Conexiones_JDBC`
- `ExamenRepaso_JDBC`
- `GestionPeliculas_JDBC`
- `PracticaVeterinaria_JDBC`
- `PreguntasTest_JDBC`
- `Superheroes_JDBC`
- `TiendaJPA`

## Materiales (`Materiales/`)

- `Materiales/UD4_Acceso_a_Ficheros/`
  - `Teoria/`: apuntes de ficheros (`ud_04.pdf`, `ud_04_resumen_ficheros.pdf`), CSV, XML con JAXB, serialización de objetos, programación funcional y expresiones regulares.
  - `Ejercicios_y_Recursos/`: enunciados (`AD_Hoja_4-02_Fich_CSV.pdf`, `enunciado_moodle.txt`), CSVs (`ciudades.csv`, `titanic_ejercicio.csv`) y código base (`App_Ciudades/`, `GestorArchivos/`).
- `Materiales/UD1_JDBC/`
  - `Teoria/`: teoría JDBC, `ResultSet` actualizable/transacciones/metadatos, scripts, SQLite y comparativa de los tres gestores (SQLite, MySQL, PostgreSQL).
  - `Enunciados_y_Soluciones/`: hojas de ejercicios (`Hoja_00_Peliculas`, `Guion_BD`, `Hoja_1-02_Consultas`, `Hoja_1-03_Veterinaria`, `Hoja_1-04_Cursos`, `Hoja_1-04_Heroes`, `Hoja_1-05_Concurso`) y recursos de `Biblioteca`.
- `Materiales/UD_JPA_Hibernate/`
  - `Taller_Hibernate_JPA_NetBeans_MySQL.pdf`
